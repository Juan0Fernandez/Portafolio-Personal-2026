# 🚀 Portafolio Personal Full-Stack | Juan Fernandez

Bienvenido al repositorio de mi portafolio personal interactivo. Este proyecto no es solo una página estática, sino una aplicación web Full-Stack construida con las mejores tecnologías modernas, diseñada para ser ultrarrápida, escalable y fácil de administrar.

🌍 **Enlace en vivo:** [juancafer.com](https://https://juancafer.com)

## 🛠️ Stack Tecnológico

* **Frontend:** [Astro](https://astro.build/) - Framework web para contenido ultrarrápido (Arquitectura de Islas).
* **Estilos:** [Tailwind CSS](https://tailwindcss.com/) - Diseño responsivo y moderno con toques de Glassmorphism y Cyberpunk.
* **Backend & Base de Datos:** [Supabase](https://supabase.com/) - PostgreSQL, Autenticación, Storage y Chat en Tiempo Real.
* **Despliegue:** [Vercel](https://vercel.com/) - Hosting rápido con CI/CD automático.

## ✨ Características Principales

* **⚡ Rendimiento Extremo:** Carga casi instantánea.
* **🌙 Temas y 🌐 i18n:** Modo Claro/Oscuro y soporte bilingüe (Español/Inglés) integrados y persistentes en el lado del cliente.
* **💬 Chat en Vivo (Live Chat):** Sistema de chat en tiempo real integrado mediante *Polling* optimizado. Los usuarios registrados pueden comunicarse directamente conmigo desde la plataforma.
* **🔐 Acceso de Administrador Secreto:** Lógica de seguridad personalizada (Easter Egg) para acceder al panel de control oculto.
* **⚙️ CMS Propio (Dashboard):** Panel de administración privado para gestionar:
  * Proyectos del portafolio (con subida de imágenes).
  * Certificados en PDF.
  * Constructor de CV Dinámico (Experiencia, Habilidades con colores y Foto de Perfil).
  * Consola de chat para responder a los usuarios.
